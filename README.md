The One-Line Cat Joke That Lands: a program that writes the funniest single-line cat joke it can — one line, 85 characters, no padding. The cat didn't bring a gift. He brought a performance review.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt`.
